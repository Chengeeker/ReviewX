# ReviewX

An Android reading app built with Kotlin, Jetpack Compose, and Material 3.

- Timelines, search, profiles, and conversations.
- Full-screen image galleries, video playback, and media saving.
- Themes, reading preferences, and WebDAV backup.

Android 7.0+ · ARM64

Back up before upgrading. Safe backups exclude credentials; full backups can contain plaintext credentials and should be kept private.
